arbitrage-rclone

arbitrage-rclone is a private, single-user tool. It uses rclone to upload backup archives of a personal research project from the owner's own server to the owner's own Google Drive.

It is not offered to other users and has no public sign-up.

Google Drive access is limited to the drive.file scope: the tool can only see and change files and folders that it created itself. It cannot read any other files in the Drive.
